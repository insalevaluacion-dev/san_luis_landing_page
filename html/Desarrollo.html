Bachillerato Técnico Vocacional en
Desarrollo de Software

¿De qué trata?

Forma tu futuro en tecnología

El Bachillerato Técnico Vocacional en Desarrollo de Software te prepara con las competencias técnicas y prácticas para diseñar, construir y mantener sistemas informáticos modernos. En tres años adquirirás habilidades reales que el mercado laboral salvadoreño e internacional demanda, desde la lógica de programación hasta el desarrollo de aplicaciones móviles.

  • 3 años de formación
  • Salida laboral inmediata
  • Proyecto final integrador
  • Inglés técnico incluido

Áreas técnicas que estudiarás

Perfil del Estudiante

  • Capacidad de comunicarse en forma oral y escrita
  • Comprensión del mundo físico y de los seres vivos
  • Destreza en matemática aritmética
  • Capacidad de resolver expresiones algebraicas
  • Manejo de jerarquía de operadores matemáticos
  • Destreza en el manejo de equipo de cómputo: teclado, mouse, etc.
  • Destreza en aplicaciones de ofimática
  • Responsable con normas de seguridad para el usuario y el equipo
  • Trabajo en grupo con actitud solidaria y tolerante
  • Capacidad de relacionarse de forma constructiva
  • Responsable en la entrega de tareas
  • Autodidacta para ampliar conocimientos adquiridos
  • Dispuesto a seguir lineamientos
  • Actúa con valores éticos

Qué se aprende en la carrera

Área Técnica:

  • Elaboración de algoritmos con lógica de programación
  • Identificación de requerimientos para sistemas informáticos
  • Diseño de Aplicaciones Multimedia
  • Manual de sistemas de calidad para desarrollo de software
  • Desarrollo de páginas Web
  • Inglés técnico: sistemas informáticos y páginas Web
  • Emprendedurismo colaborativo
  • Proyecto tecnológico de desarrollo de páginas Web

  • Diseño de Arquitectura de Software
  • Programación de componentes de Base de Datos
  • Programación Orientada a Objetos
  • Diseño e instalación de Redes LAN
  • Inglés técnico: arquitectura de software y base de datos
  • Diseño de planes de negocio en asociatividad cooperativa
  • Proyecto innovador de desarrollo de portales Web
  • Desarrollo de aplicaciones de software para solución de problemas
  • Mantenimiento y aseguramiento del sistema informático
  • Administración de Bases de Datos
  • Documentación de Sistemas Informáticos
  • Desarrollo de componentes para dispositivos móviles
  • Inglés técnico: mantenimiento de sistemas informáticos
  • Puesta en marcha de microempresa cooperativa
  • Proyecto innovador de desarrollo de Software
